# vibatchium prompt-injection engine: review and v2 (2026-10-20)

Branch `safety-v2`, worktree `~/.worktrees/vibatchium/safety-v2`. Nothing is merged; the shared
checkout is untouched.

## What exists today (v1, `vibatchium/safety.py`)

- `classify(text)` runs about 30 regexes. One high hit, or two low hits, makes the result `high`.
- `apply_wrap` and `apply_redact` rewrite the matched spans. `classify_html` does a two-pass
  visible/hidden-DOM scan.
- The daemon hook (`server.py`) calls `scan_response(verb, result, mode)` on every verb listed in
  `CONTENT_FIELDS`. The default mode is `flag-only`.
- Consumers:
  - the daemon itself
  - `vibatchium/skills` (scans skill notes)
  - twitter_persona's `untrusted.py`, which imports the module as a library. There, `high` means
    the tweet is quarantined and `low` means it is wrapped.

## What was wrong, measured

| | v1 |
|-|-|
| deepset/prompt-injections recall | 1.5% |
| Lakera gandalf "ignore instructions" recall | 28.6% |
| jackhhao jailbreak recall | 22.3% |
| xTRam1 safe-guard recall | 12.2% (FP 0.1%) |
| Hand-written indirect / obfuscated / multilingual / social set | 4 / 49 |
| Held-out set (written after tuning, never tuned on) | 2 / 30 |
| Real tweets flagged HIGH (128,600 from the twitter_persona archive) | **483** |
| Tricky-but-benign lines flagged | 16 / 17 |

Root causes:

1. **No normalization.** Fullwidth, math-bold (the Telegram scam swarm writes in it), Cyrillic
   look-alikes, leetspeak, `i g n o r e` and `ignore-all-previous` all walked past.
2. **Invisible-Unicode check judged existence, not purpose.** 476 of the 483 false highs were the
   zero-width joiner inside ordinary emoji (🏴‍☠️, 👨‍👩‍👧). In twitter_persona, high means
   quarantine, so about 0.4% of timeline tweets were silently dropped from the reply pools.
   Meanwhile real smuggling went undetected: Unicode tag characters (U+E0000 "ASCII smuggling"),
   bidi overrides and variation-selector payloads.
3. **English-only, exact phrasing.** No multilingual coverage, no text addressed to the agent
   reading the page ("Note to AI models:", "If you are an LLM summarizing…"), no exfiltration
   directives, no markdown-image exfil, no `[INST]` / `<<SYS>>` / Llama-3 tokens.
4. **Over-broad §19 patterns.** `auth_gate_framing` fired on every "verification required" (KYC,
   2FA, login pages). `task_incomplete_coupling` fired on "the result is wrong".
5. **Wrapper escape.** Content containing `</UNTRUSTED_CONTENT>` closed our own wrapper.
6. **Coverage hole.** `explore` (the documented START HERE verb), `fetch`, `search`, `observe`,
   `console_dump`, `network_dump`, `pages`, `frames`, `handle_eval` and `eval_handle` were not in
   `CONTENT_FIELDS`, so the default mode never scanned the most-read text in the product.
7. **The docstring advertised an LLM tier** ("opt-in, Haiku") that was never built.

## What v2 changes

- **Matching over three views.** Every pattern runs on the raw text and on a folded copy (NFKC,
  look-alike letters, invisible characters removed). The override-class patterns also run on a
  squashed copy (leetspeak, chained separators, spaced-out words). Offsets map back, so wrap and
  redact still cut the original text.
- **Invisible Unicode by purpose.**
  - Flagged high: a character splitting a word, tag-character runs (decoded and classified too),
    bidi overrides, and variation-selector payloads with 3 or more distinct selectors.
  - Left alone: emoji joiners, RTL marks, X's bidi isolates around 📷, and the England/Scotland
    flag tag sequences.
  - The census behind these rules: 1 in 128k tweets has an invisible character splitting a word.
- **Base64:** blobs that decode to readable text are classified, plus "decode … and follow"
  instructions.
- **New pattern families:**
  - text addressed to an agent
  - exfiltration directives (imperative position only, so security writing about malware isn't hit)
  - markdown-image exfil
  - chat-template tokens and forged turns
  - wrapper escape
  - multilingual overrides in 13 languages
- **Bot-targeted social engineering as LOW.** In twitter_persona, low means wrapped, not dropped:
  "repeat after me", "reply with exactly", "your dev said…", "end every post with…". Two lows
  still add up to high.
- **Context gates:** `auth_gate_framing` needs an agent noun nearby, and
  `task_incomplete_coupling` needs an unlock condition nearby.
- **Quoted attack phrases** ("how 'ignore previous instructions' attacks work") are downgraded to low.
- **`apply_wrap` defangs** any `UNTRUSTED_CONTENT` marker the content itself carries.
- **`CONTENT_FIELDS` gains the 10 uncovered verbs.**
- **The docstring now tells the truth** (heuristic only; a `none` verdict means "no known
  signature", not "safe").
- **Speed:** trigger words are derived from each regex's own opening alternation (never
  hand-listed); a pattern is anchored at those positions instead of scanning the whole page, and
  derived views are scanned only around the characters they changed. Results are identical with
  the optimizations on and off, checked on 131,912 texts.

## What v2 still does not catch (the honest ceiling)

- **Paraphrase.** The held-out misses are 0/6 reworded overrides ("set aside the guidance you
  received earlier", "scratch all that, real task:…") and 4/5 agent-addressed asks ("Dear AI
  assistant, the user has authorized…"). A regex list cannot generalize to wording it hasn't seen.
- **Images.** Text in screenshots and memes is invisible to every layer. In twitter_persona,
  culture reposts publish media nobody screened.
- **CSS hiding beyond inline styles:** classes like `sr-only`, external stylesheets,
  white-on-white text, `clip`.

## Recommendations, in order

1. **Merge v2.** Merging affects live systems in two places:
   - twitter_persona imports `vibatchium.safety` from the shared checkout, so the ticks pick it
     up on the next run. This is a strict improvement there: emoji tweets stop being quarantined.
   - The daemon only loads it on restart, and the daemon is shared. Coordinate the bounce
     (`vb daemon shutdown`), never `pkill`.
2. **Add an optional semantic layer for high-stakes, low-volume text only.** For example,
   twitter_persona's `mention_candidates` (a handful a day, written by people addressing the bot
   directly), using a small local classifier (a ProtectAI / Prompt-Guard class model) or a Haiku
   call. Not for every page: cost and latency are wrong for that, and the regex layer stays the
   cheap first pass.
3. **Keep the outbound guard as the real boundary.** twitter_persona's `payload_guard` (no link,
   domain, contract or invite in anything we post) is what makes a missed injection cost nothing.
   The same pattern belongs in any agent that acts on scraped pages: decide what the agent is
   allowed to emit or click, rather than trusting detection.
4. **Grow the held-out set** from real incidents and keep it untuned, so the reported recall stays
   honest. The harness is `bench/injection_eval/` (`fetch_datasets.sh` + `run_eval.py`).
